# Swift Loop docs

Hey. These docs are written for designers, not engineers. You don't need to know what an AST is, you don't need to have written a Figma plugin before, and we promise to keep the math friendly.

## Start here

If this is your first time:

[Getting started](./getting-started.md). How to install and make your first loop.

[Controls reference](./controls.md). Every slider and toggle in the UI, in plain language.

## Make things

[Pattern gallery](./pattern-gallery.md). All 33 built-in patterns, with what they look like and when to reach for them.

[Recipe cookbook](./recipes.md). "I want to make X" with step-by-step settings.

[Modulation](./modulation.md). Randomness, sine waves, and how to make a tidy grid feel a little alive.

## Go deeper

[Formulas for designers](./formulas.md). `fx` mode demystified. If you've used Desmos or written a CSS animation, you can do this.

[Troubleshooting](./troubleshooting.md). Undo behavior, performance, "why is my preview different from the canvas".

## For the robots

[Pattern authoring guide for LLMs](./llm-pattern-guide.md). A self-contained reference you can paste into Claude or ChatGPT to get help designing new library patterns from a plain-English description.
