# Swift Loop docs

Hey. These docs are written for designers, not engineers. You don't need to have written a Figma plugin before, and there's no math here at all.

## Start here

[Getting started](./getting-started.md). How to install Swift Loop and make your first loop, plus a plain-language tour of every control in the panel.

[Troubleshooting](./troubleshooting.md). Undo behaviour, performance, "why won't it loop my selection".

## Related projects

Swift Loop is a faithful rebuild of the original Looper. If you're exploring the family:

[Looper](https://github.com/kuldar/figma-looper). The original, by Kuldar Kalvik.

[Looper Legacy](https://github.com/girafic/figma-looper). A fork by Stas Haas that kept it alive.

And if you're after the earlier, formula-flavoured direction of Swift Loop (grids, custom math, a big pattern library), it's preserved on the [`main-archive-2026-06`](https://github.com/Swiftner/swift-loop/tree/main-archive-2026-06) branch.
